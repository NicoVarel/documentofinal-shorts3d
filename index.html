Antes de empezar

Solo necesitás 3 cosas

Elegís uno de los dos estilos y la IA te acompaña con las herramientas correspondientes. No hace falta instalar programas para ambos.

💻

Computadora

Windows o Mac, con espacio suficiente para el render. La IA revisará los requisitos de tu equipo.

🤖

Claude Code

Un agente con acceso autorizado a archivos y terminal. Le darás los prompts de instalación y producción.

🎙️

ElevenLabs

Una cuenta para generar la narración mediante API. El uso está sujeto a la cuota y al plan disponible.

🎬

Una idea

Una curiosidad, explicación, historia o tema. La Skill te ayudará a convertirlo en un Short vertical.

El repositorio Shorts-zack-films-3d ofrece dos estilos diferentes: caricatura con Remotion/Three.js o 3D realista con Blender. Para obtener un resultado profesional pueden requerirse ajustes y recursos adicionales.
Guía fácil y práctica

Creá tu primer Short en 6 pasos

Copiá cada prompt en Claude Code y seguí las instrucciones. No necesitás saber programar: la IA te ayuda con la instalación, la voz y el render.

1

Instalá la Skill desde GitHub

La Skill correcta es NicoVarel/Shorts-zack-films-3d. Abrí el repositorio oficial ↗. Después copiá este prompt en Claude Code para que revise el código y te acompañe en la instalación.

QUIERO INSTALAR EXACTAMENTE ESTA SKILL (Y NO OTRA):
https://github.com/NicoVarel/Shorts-zack-films-3d

Nombre del repositorio: NicoVarel/Shorts-zack-films-3d

Sigue estos pasos en mi computadora:
1. Abre y comprueba ese repositorio exacto. Antes de descargar o ejecutar nada, revisa README.md, SKILL.md, plantillas/, realista/, herramientas/ y las instrucciones de seguridad. No uses otro repositorio ni versiones anteriores de otra Skill.
2. Descarga únicamente el repositorio indicado a una carpeta nueva de proyecto. Revisa scripts y dependencias antes de instalarlos, sin ejecutar código remoto directamente.
3. Lee su SKILL.md completo y sigue SU flujo de trabajo. Muestra los dos estilos que documenta: CARICATURA ANIMADA (personajes planos con contorno en entorno 3D, Remotion/Three.js) y 3D REALISTA (Blender).
4. Pregúntame qué estilo quiero. No mezcles sus dos sistemas. Instala solo las herramientas de ese estilo, con mi autorización explícita, e indica descargas y costos posibles.
5. Comprueba sus ejemplos y prepara una prueba corta fiel a las referencias de estilo del repositorio. Si faltan recursos, busca alternativas legítimas y explica limitaciones.
6. Configura la carpeta como Skill de Claude Code solo si corresponde a las instrucciones del repositorio. Mantén archivos personales y claves fuera del proyecto y de GitHub.
7. Confirma la ruta local y qué prueba realmente funcionó.

IMPORTANTE: el repositorio correcto es Shorts-zack-films-3d. No sustituyas esta Skill por Skill-shorts-3d-virales ni por Shorts 3D Faceless v5/v8.
No hace falta descargar nada desde esta página. Claude Code necesita acceso autorizado a tu computadora para instalar archivos; un chat sin acceso a archivos solamente podrá explicarte los pasos.
2

Elegí el tipo de animación

La Skill contiene dos estilos distintos. Elegí uno antes de continuar; así no instalás herramientas innecesarias.

🎨Caricatura animadaPersonajes planos y escenarios 3D de colores. Usa Three.js y Remotion.
🎥3D realistaMateriales, luces y cámara 3D en Blender. Requiere recursos y render más exigentes.

Respondé a Claude con el estilo que preferís y pedile que prepare una escena corta de prueba.

3

Conectá ElevenLabs para crear la voz

No necesitás grabar tu voz. ElevenLabs generará la narración a través de su API. Primero copiá este prompt en Claude Code para preparar la conexión segura:

Quiero configurar ElevenLabs para generar la narración de mis Shorts 3D desde mi proyecto local.

1. Comprueba si la Skill Shorts 3D instalada desde https://github.com/NicoVarel/Shorts-zack-films-3d ya incluye integración con ElevenLabs. No afirmes que existe si no está implementada.
2. Si no existe, agrega una integración mínima y segura con la API oficial de texto a voz de ElevenLabs, sin modificar archivos ajenos al proyecto.
3. Explica cómo crear una clave restringida únicamente para Text to Speech y cómo establecer un límite de créditos.
4. Prepara el proyecto para leer la clave desde la variable de entorno ELEVENLABS_API_KEY o desde un archivo local .env que esté en .gitignore. No escribas ni imprimas la clave en registros, el código fuente, prompts, pantallas o archivos exportados.
5. Pídeme que coloque personalmente la clave en mi entorno local. No me solicites pegarla en esta conversación.
6. Permíteme elegir una voz en español, genera una prueba de una sola frase previa autorización y revisa pronunciación, naturalidad y consumo estimado de créditos.
7. Si la API está inhabilitada, no hay saldo o falla la autenticación, explícame el error y ofrece una alternativa sin exponer credenciales.

Antes de generar un audio largo, confirma la voz y la calidad de la muestra.

¿Dónde se crea la API Key de ElevenLabs?

  1. Entrá a elevenlabs.io ↗ e iniciá sesión o creá tu cuenta.
  2. En la barra lateral izquierda, abrí Developers (Desarrolladores).
  3. Entrá a la pestaña API Keys y creá una nueva clave.
  4. Poné un nombre identificable, por ejemplo Shorts 3D. Mantené la clave restringida y habilitá solamente lo necesario para Text to Speech.
  5. Configurá un límite de créditos y copiá la clave al crearla: ElevenLabs solo muestra la clave completa una vez.
  6. Guardala localmente siguiendo las instrucciones de Claude Code (variable de entorno o .env excluido de Git). No la pegues en el chat ni en GitHub.

Guía oficial: Cómo crear y proteger una API Key ↗

La API puede consumir créditos según tu plan. Una clave de API no crea créditos gratuitos ni garantiza que una función esté incluida en tu cuenta.
4

Elegí tu idea y generá el guion

Decile a la IA de qué querés hablar. Te preparará el gancho, la narración y un storyboard adaptado al estilo que elegiste.

Ya instalé la Skill del repositorio https://github.com/NicoVarel/Shorts-zack-films-3d y preparé ElevenLabs.

Quiero producir un Short faceless sobre: [ESCRIBE AQUÍ TU TEMA].
Estilo elegido: [CARICATURA 3D / REALISTA CON BLENDER].
Duración objetivo: [30–45 SEGUNDOS].
Idioma: español.

Investiga los hechos relevantes, verifica los datos, proponme un gancho muy atractivo para los primeros 3 segundos y construye un guion con narración natural y sin relleno.

Después crea un storyboard escena por escena con duración, personajes, fondos, objetos, materiales, iluminación, movimientos de cámara y sonido. Mantén la estética del estilo elegido y no copies literalmente videos ajenos.

Antes de renderizar el video entero, muéstrame una vista previa visual corta para revisar la calidad de modelos, texturas y fondos.
Consejo: empezá con una explicación visual fácil de comprender, por ejemplo una paradoja, un invento o una curiosidad histórica. Verificá los datos antes de publicar.
5

Generá voz, personajes y escenas

Con el guion aprobado, pedile que cree la narración de ElevenLabs y prepare los modelos, los escenarios y la animación. Revisá una vista previa antes de renderizar todo.

Continúa con el guion y storyboard aprobados de mi Short 3D.

1. Usa exclusivamente el estilo seleccionado de la Skill: caricatura con Remotion/Three.js o realista con Blender.
2. Genera la narración mediante la integración local segura de ElevenLabs, usando la voz que ya elegimos. No muestres ni expongas la API key.
3. Sincroniza los tiempos de la narración con las escenas. No cortes palabras ni inventes silencios.
4. Produce fondos y modelos detallados, iluminación consistente y movimiento de cámara fluido. Usa recursos con licencia cuando haga falta.
5. Genera una previsualización corta y revísala visualmente. Corrige personajes, materiales, composición o errores antes del render completo.
6. Monta las escenas con efectos sonoros apropiados, música con licencia y subtítulos legibles, sin tapar el contenido importante.
7. Exporta un MP4 vertical 1080×1920, verifica su imagen, voz, duración y ausencia de fotogramas negros.
8. Entrega el MP4, archivos editables, título, descripción y lista de recursos utilizados.

Si una herramienta no está disponible, explícame la alternativa y su efecto en la calidad. No prometas un render final que no has comprobado.

Si un personaje o un fondo se ve barato, indicá el defecto concreto: materiales planos, mala anatomía, iluminación pobre o movimiento rígido. Pedí corregir la escena, no empezar todo de nuevo.

6

Revisá y exportá el video

Escuchá la voz, comprobá el ritmo de cada escena y verificá que los gráficos no se corten. El resultado esperado es un Short vertical en MP4, con narración, subtítulos y recursos con licencia.

Preguntas frecuentes

¿Tenés alguna duda?

¿La Skill hace videos automáticamente?

Te guía y automatiza partes de guion, voz, escenas y render. La calidad final depende del estilo, los recursos instalados y la revisión del proyecto. Descargar la Skill no produce un video instantáneo.

¿Hace falta grabar mi propia voz?

No. La guía está pensada para narración generada con ElevenLabs mediante API. Se configura de forma local y protegida en tu computadora.

¿ElevenLabs es completamente gratis?

El uso de la API depende de los créditos y condiciones de tu plan; verificá los límites antes de generar una locución larga.

¿Cuál es la diferencia entre los estilos?

El estilo de caricatura usa Three.js/Remotion; el realista usa Blender y modelos, iluminación y materiales más elaborados. No es necesario instalar las dos rutas.

¿Debo compartir mi API Key con Claude?

No la publiques en chats ni repositorios. Pedile a Claude Code que prepare un archivo local protegido o una variable de entorno, y colocala vos personalmente. Limitá sus permisos y créditos.

¿De dónde vienen los videos de ejemplo?

Son referencias visuales aportadas para ilustrar posibles temas. No se presentan como resultados generados por esta Skill. Revisá los derechos antes de reutilizar material ajeno.
